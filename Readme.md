# 💌 Contact Form

A modern and responsive **Contact Form** built using **HTML** & **CSS**.  
This form allows users to submit their contact details and messages in a stylish, professional layout, ideal for portfolio or business websites.

---

![Contact Form Preview](/Image/preview.png)

---

## ✨ Features

- 🧍‍♂️ Input fields for name, email, phone, subject, and message
- 💌 Smooth and elegant UI with subtle animations
- 🧭 Responsive layout for all screen sizes
- 🎨 Dark-themed modern design with accent colors
- ⚡ Interactive hover and focus effects

---

## 🛠️ Technologies Used

- 🧱 **HTML**
- 🎨 **CSS**
- 🧩 **Font Awesome** (for icons)
